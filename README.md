# 討論卓 — Debate Prompt & Record

議題をひとつ投げると、4人の論者と1名の司会が討論するプロンプトを生成し、
**その討論結果を構造化して記録・可視化する**、完全ローカルの個人ツール。

会議のファシリテーションを任されたときに、
「どんな意見が出るか」「どこで揉めるか」「何と返すか」を事前に洗い出して持ち込むために作った。

- ビルド不要・依存ゼロ・サーバー不要・アカウント不要
- データはブラウザの localStorage にだけ保存され、外に出ない
- `index.html` をブラウザで開くだけで動く（`file://` でも可）

---

## 使い方（4ステップ）

```
① compose.html   議題を入力 → 討論プロンプトを生成 → コピー
② ChatGPT        貼り付けて討論させる（4論者 × 2〜5ラウンド）
③ import.html    構造化プロンプトをコピー → 同じチャットに投げる → 返ってきた JSON を貼る
④ record.html    論点マトリクス・議論フロー・想定問答集として保存・閲覧
```

議題・カテゴリ・ラウンド数は ① から ③ へ自動で引き継がれるので、入力は1回で済む。

### ③ で JSON が途中で切れたら

取り込み画面の「PART 1（論点・発言）」「PART 2（リスク〜総括）」に切り替えて2回に分けて出させ、
それぞれを「解析して追加」で読み込む。自動でマージされる。

前後に説明文が付いていても、コードブロックのまま貼っても、末尾カンマや全角引用符が混じっていても、
取り込み側で自動修復する。

## 画面

| ページ | 役割 |
|---|---|
| `index.html` | ダッシュボード。記録一覧・全文検索・タグ絞り込み・統計・バックアップ |
| `compose.html` | 議題設計と討論プロンプト生成（14カテゴリ × 4論者 × 2〜5ラウンド） |
| `import.html` | 構造化プロンプト生成と JSON 取り込み |
| `record.html?id=…` | 記録詳細。下記4つの可視化 |

### 記録詳細で見られるもの

1. **論点 × 論者マトリクス** — どの論点で誰が賛成／反対／条件付きか。丸の濃さが論の強さ、左の点が重要度。会議前に一番効く画面
2. **議論フロー図** — 横がラウンド、縦が論者。赤い破線が「誰が誰の前提を潰したか」
3. **リスク／アイデアの3×3マトリクス** — リスクは「起こりやすさ × 影響」、アイデアは「効果 × 労力」
4. **想定問答集** — 論点ごとに「出そうな意見／言いそうな立場／こちらの返し／根拠／無視した場合」。印刷するとこのセクションだけが紙面に出る

ほかに、決定事項・タスク（チェック可）・未解決論点・司会の総括。
未解決論点からは **その論点だけを2ラウンドで詰め直す「続きの討論」プロンプト** をその場で生成できる。

## データについて

- 保存先はブラウザの localStorage（`debate-app:` プレフィックス）
- **ブラウザの閲覧データを削除すると記録も消える**。ダッシュボード下部の「JSON で書き出す」で定期的に控えを取ること
- 別の端末で見たいときも、書き出した JSON を持っていって「ファイルから読み込む」
- 記録1件あたり 10〜20KB 程度。上限の目安は 5MB 前後

## ファイル構成

```
index.html            ダッシュボード
compose.html          討論プロンプト生成
import.html           構造化・取り込み
record.html           記録詳細
debate-table.html     旧ファイル（compose.html へリダイレクト）
assets/
  tokens.css          デザイントークンと共通部品
  catalog.js          14カテゴリ・論者・ラウンド構成・トーンの定義
  prompt.js           討論プロンプト／構造化プロンプト／深掘りプロンプト
  schema.js           debate-record/v1 スキーマ・正規化・検証・JSON修復
  store.js            localStorage CRUD・エクスポート／インポート
  ui.js               ナビ・DOMヘルパー・コピー・ポップオーバー
  charts.js           マトリクス・フロー図・3×3マトリクスの描画
  qa.js               想定問答集と Markdown 書き出し
samples/
  sample-record.json  サンプル記録（正）
  sample-record.js    上記を file:// でも読めるようにした同梱版
```

ES Modules を使っていないのは `file://` で開けるようにするため。すべて `window.DA` 名前空間。

`assets/catalog.js` の `GROUPS` にカテゴリを追加すれば、自分の職場専用の卓（部長役・経理役・現場役・若手役など）を作れる。

## 記録フォーマット `debate-record/v1`

`assets/schema.js` が定義元。取り込み画面が生成するプロンプトにそのまま埋め込まれる。

```
meta        タイトル・カテゴリ・ラウンド数・日付・タグ・参加者
issues      論点（重要度・状態・各論者の立場と強さ・未解決点）
moves       発言（ラウンド・論者・種別・要点・攻撃対象・撤回/修正/強化）
risks       リスク（起こりやすさ・影響・対策）
ideas       アイデア（効果・労力）
decisions   決定事項      tasks  タスク
objections  想定問答（会議で出そうな意見と返し）
summary     推奨案・理由・トレードオフ・見落とし・次の問い
```

## これから足せるもの

- **予測 vs 実際の突き合わせ** — 会議後に「出た／出なかった／想定外」を記録し、自分の読みの癖を蓄積する（スキーマの `objections.actual` は既に用意済み）
- ファシリ台本／時間配分付きアジェンダの生成
- 1論者だけ呼ぶ壁打ちモード
- PWA化してスマホのホーム画面から想定問答集を開く
- 全記録を横断して「繰り返し刺さる反対意見」を集計
